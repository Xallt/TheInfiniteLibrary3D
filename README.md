# Three.js Interactive Book Project

This project demonstrates an interactive 3D book using Three.js and TypeScript.

## Setup and Running the Project

1. Install the project dependencies:
   ```
   npm install
   ```

2. Start the development server:
   ```
   npx vite
   ```
   Open the provided URL (typically `http://localhost:5173`) in your web browser to view the project.
